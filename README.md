# RimoWorld！

大家有玩过RimWorld这款游戏吗？

RimWorld非常好玩！

但是游戏中对温度的表现不太直观，经常没注意殖民者就得了低温症，或者殖民者发狂原来是因为昨天晚上睡觉冷到了。

所以聪明的莉沫酱发明了1个RimoWorld<sub>(注意这个拼写不1样)</sub>，可以让玩家的房间里的空调也变冷，这样玩起来就有身临其境的感觉，再也不会忘记给殖民地修暖气了！


## 依赖

首先需要这个mod:

- [Rimworld-API](https://github.com/RimoChan/Rimworld-API)。有了这个mod就可以方便地通过API获取游戏里的温度之类的状态了<sub>(其实也是我写的)</sub>。

- 然后空调得是智能空调，这里是通过[Home Assistant](https://www.home-assistant.io/)接入的。


## 使用方法

首先在你的Home Assistant服务器上，添加1个长期访问令牌，把令牌粘贴到`w.py`里。

然后打开游戏，同时运行`python w.py`就可以了！这个脚本会每1秒去查询游戏里的各个卧室温度的平均值，然后来调整玩家的空调的温度。
